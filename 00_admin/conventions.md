# Conventions

## Folder naming
Use:
- lowercase
- underscores
- numeric prefixes for ordered sections

Examples:
- `01_topics`
- `02_interview_prep`
- `03_projects`
- `01_topics/02_advanced_concurrency`

## Topic folder structure
Each topic should contain:

- `notes.md`
- `finance_connection.md`
- `interview_questions.md`
- `code/`
- `exercises/`
- `assets/`

## File naming
Use descriptive names.

Good:
- `race_condition_example.java`
- `atomic_integer_notes.md`
- `exercise_01_thread_safe_counter.md`

Avoid:
- `test.java`
- `notes2.md`
- `file_final_final.md`

## Writing style
- short paragraphs
- simple explanations first
- always connect technical concepts to a financial use case when possible

## Git rule
Do not commit:
- confidential work material
- proprietary banking content
- restricted university content
- credentials or secrets

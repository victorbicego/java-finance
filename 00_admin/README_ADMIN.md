# 00_admin

This folder contains the study management layer of the `java-finance` repository.

## Purpose
Keep the repository structured, consistent, and easy to maintain over time.

## What belongs here
- long-term roadmap
- weekly study plan
- topic index
- conventions for naming files and folders
- progress tracking
- goals for interview preparation

## What should not go here
- code
- topic-specific notes
- project source files
- PDFs or general study resources
